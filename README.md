
## Getting Started

First, you need to get the backend code at this url and follow the instructions in the README:
https://github.com/OpenClassrooms-Student-Center/dev-react-P10 


Then, run the development server:

```
cd project
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

To test you can use the following credentials or create your own:
